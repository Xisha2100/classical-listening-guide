# 柴可夫斯基《第一钢琴协奏曲》Op.23：乐句与曲式边界研究记录

本文件及同目录 `phrase-analysis.json` 是 **GPT-6 Sol 本轮分析**（2026-10-31），尚未经过人工听审或逐音人工校勘。它不替代权威校订总谱。`role=theme` 表示在当前证据下可作完整一轮主题播放；`role=phrase` 表示一段相对完整的陈述或应答；`role=evidence` 只提供局部谱例。`certainty=candidate` 的起止或分类仍待人工核界，不能在界面上显示为已经核定的完整主题。

## 实际查阅的资料

1. **本地数字总谱，source id `tcha-op23-local-score`。** PDMX v9 所归档的 [jeronjoseph MuseScore 原谱页](https://musescore.com/user/20208436/scores/5871238)，下载记录见 [Zenodo PDMX v9](https://zenodo.org/records/15571083)。本地 `source-complete.mxl` 及拆出的 `movement-1.mxl`、`movement-2.mxl`、`movement-3.mxl` 是所有精确播放边界的直接依据。`movement-*-measure-map.json` 把印刷小节号与内部序号相联；生成的 `events.json` 用于核查所选谱表有可播放音符。源网页标题只写第一乐章，但保留的 MXL 实际有三乐章；这一事实已由本地 MusicXML 的三个乐章、17 个乐器声部／18 个谱表及 669+170+301 个小节元素复核。**具体修订版没有完全核对。**
2. **Robert Gauldin, “Tragic Love and Musical Memory,”** *Music Theory Online* 10/4 (2004)，[主文](https://www.mtosmt.org/classic/mto.04.10.4/mto.04.10.4.gauldin.html)，特别是 §§17–21；[Example 5a–l](https://mtosmt.org/issues/mto.04.10.4/gauldin_examples.pdf)，PDF 第1–2页。Gauldin 指出第一乐章引子旋律原形不回归、主部民歌型材料、复合副题组、华彩内部多次主题与发展、第二乐章法国歌曲材料，以及终乐章近回旋设计和一个抒情插段。其“人名音型／爱情回忆”解释是分析假说，不作为本标注的事实陈述。
3. **Bernadette Beyne 与 Quentin Mourier，**[《Les Concertos du Concours : le 1er Tchaikovski – Guide d’écoute》](https://www.crescendo-magazine.be/conc-tchaiko_quentin_corr/)（*Crescendo Magazine*，2016），第一乐章 Introduction / Allegro / Développement / Réexposition，第二乐章 A–B–A，第三乐章 Rondo / Coda。其导听文附实际录音片段和谱例，明确第二主题先由单簧管、后由钢琴奏出；第三主题先由弱音弦乐奏出；第101小节的终乐章对比段属于过渡。其第一乐章编号亦有版本偏差，必须与本谱核对。
4. **Tonic Chord, “Tchaikovsky: Piano Concerto No.1 Analysis”**（2018），[全文](https://tonic-chord.com/tchaikovsky-piano-concerto-no-1-analysis/)，网页 *First Movement*（引子、呈示、展开、再现）、*Second Movement*（A–B–A）与 *Third Movement*（A–B–A–C–A–B–A）各节。其第二、三乐章标注范围与本谱 170、301 个印刷小节基本相合；第一乐章后部小节号有明显冲突，只取其主题功能线索，不能直接移植其数值。
5. **Mayuko Wada, PTNA Piano Music Encyclopedia，** [Op.23 条目](https://enc.piano.or.jp/en/musics/92)，Commentary 的三个乐章段落。其总括为第一乐章奏鸣曲式、第二乐章长笛主题与对比中段、终乐章回旋曲式。网站注明英文为自动翻译、未经原作者审校，因此仅辅助核对大结构。
6. **Tchaikovsky Research，** [Op.23 作品条目](https://en.tchaikovsky-research.net/pages/Piano_Concerto_No._1)及[Scores 页](https://en.tchaikovsky-research.net/pages/Piano_Concerto_No._1%3A_Scores)，用于了解1879与1888–89年修订、终乐章删节及版本目录。不能据此单独判定本地 MXL 的修订版。

Joshua John McKinnis（2023）[论文条目](https://digitalcommons.liberty.edu/masters/1025/)的摘要可读，但正文下载返回 403；本轮**未用其正文作为边界依据**。其他搜索摘要、与此作品不符的节目说明亦未入证据链。

## 谱号、版本与可播放边界

- 第一乐章有 **669 个内部小节元素，末尾印刷号 666**。印刷 48 后另有 `X1`（内部49），随后印刷49为内部50；印刷607后还有 `X2`、`X3`（内部609、610），随后印刷608为内部611。第二、三乐章的内部序号与印刷号一一对应，分别至170、301。JSON 的 `measures` 是印刷号（两端包含），`ordinal_measures` 是本地事件谱所用的一起始内部序号（两端包含）。若播放从印刷607持续到611，必须纳入其间 `X2` 与 `X3`，即内部608–614。
- 第一乐章本谱印刷 **109**（内部110）为 Allegro con spirito 的4/4入口；印刷 **293**（内部294）的 Poco più sostenuto 与钢琴退出、弦乐进入，是展开部的可靠入口；印刷 **448**（内部449）开始钢琴十六分音符密集织体，藏有再现主部节奏；印刷 **538**（内部539）有 `Cadenza`，印刷 **603**（内部604）有 `Quasi Adagio`，印刷 **612**（内部615）有 `Tempo I`，印刷613附近乐队重新加入。Tonic Chord 的第一乐章条目却将华彩记为568、尾声主题记为642，均较本谱的对应谱面节点约晚30小节；其末尾还列到685，而本谱印刷终点为666。Crescendo 在第一乐章记展开约289、再现约448，与本谱展开293、再现448只有局部相符；其副题导听编号185/204附近与本谱单簧管185、弱音弦乐205也有差别。无法用一个固定偏移解释全段，故本轮没有强制做全局外部编号换算。
- Tonic Chord 第一乐章主部写108，而本谱印刷109有明确速度/节拍切换；这也显示外部编号与本谱不能默认相同。第一乐章较早段的主题候选是结合外部功能描述、本谱速度/配器变化和事件起点重新划定。`candidate` 提醒读者尚未逐音对照另一修订版。
- 第二乐章本谱印刷 **59**（快速中段）和 **146**（Tempo I）为清晰的大段界；第三乐章 **45、49、56、101、114、122、126、133、138、214、243、252、271** 等速度/织体变化与回旋叙事互相参照。第三乐章终点301与 Tonic Chord 相合，但这不足以证实全谱的修订版。

## 主题与乐句范围的取舍

第一乐章第1小节圆号 F—降D—C 自小节四分音符偏移1.5处起，只是短动机。宽广旋律由小提琴/大提琴在第7小节偏移1.5处弱起，到第16小节偏移0.5处排他收束；第16小节偏移1.0处已有下一句的 F5，不能直接圈整小节当一个完整句。钢琴第24–32小节装饰重述。快板主部第109小节钢琴起句实际音高为 E4–F4–降G4–F4，而 `events.json` 的 `name` 字段只给音名字母、不显示升降号，具体音高由 MIDI 值/原谱临时记号交叉核对。主部第135小节长笛以 F–G–降A–G 接续，故旧稿第134小节作为木管主题起点不成立。

降B调单簧管在第185小节记谱为降E5–B4–C5，实音为降D5–A4–降B4，钢琴第193小节复述该旋律；第184小节仍是钢琴前段低音敲击，不属于新主题主旋律。第205小节第一小提琴从四分音符偏移1.0处奏降E4–F4–G4，与第204小节钢琴尾音和第205小节钢琴起始C大调终止和弦分开，是另一抒情主题。第一小提琴的连线以两小节为一组，第212小节末有休止，第213小节另起扩展，因此205–212是完整首轮。第219小节长笛、第227小节双簧管携带第二主题材料，钢琴多为装饰，旧稿只选钢琴误把伴奏当完整主题，已改为局部 `evidence`。Crescendo 和 Gauldin 均支持这一复合副题身份；单簧管185–192后整小节休止，钢琴193–205接句，钢琴第205小节偏移1.0时恰有新弦乐主题进入；这些换奏、连线和休止支持完整初轮。其他延长段仍保留 `candidate`。

展开从本谱第293小节的新速度和弦乐主题进入开始，钢琴一度休止；旧稿照搬 Tonic Chord 第321小节不成立。第448小节再现时钢琴密集短音中可见主部节奏，但不应称完整钢琴八度主部。第472小节双簧管降E5–B4–C5，与第185小节单簧管实音保持同一音程轮廓并整体上移全音；第479小节尾音后双簧管休止，第480小节长笛/小提琴同奏，至第492小节起始 D4 四分音符收束（排他终点偏移1.0），第493小节钢琴复述。旧稿把第481–500小节写作钢琴主部，事实相反：第481小节钢琴高谱表无音，旋律在长笛和小提琴。前两轮再现的换奏与收束证据较明确；钢琴第493小节后的扩展则只标 `evidence`。第538–611小节华彩整体有谱面标题和乐队长时间静默支持；Gauldin 的“三段”没有足以直接移植的本谱内部句界，本轮没有均分成三个“完整乐句”。

第二乐章第5–12小节长笛与13–20小节钢琴形成主旋律的问答；第20小节与下一转调短句重叠，故20小节边界标候选。第42–49小节大提琴和50–57小节双簧管（第58小节已休止）的配器接力，与 Gauldin 主文脚注16及 Tonic Chord 的具体小节描述一致。中段第80小节末大提琴弱起，第81小节进入法国歌曲旋律，钢琴同期反复两音作装饰；第98小节有乐队变奏。旧稿以钢琴为歌曲主旋律不成立。本轮保留80–97为“候选主题范围”，并附弦乐/木管短证据；整轮中的换奏及句末仍需人工核对。第114–145小节回到先前快速材料并有准华彩，未把每个短动机冒充“主题”。

第三乐章第5–44小节 A 舞蹈材料内部的第21小节是可见的移调重起，因此分为首轮5–20与接续21–44。第56–79和133–149的抒情插段归为同一 B 主题家族。第101–113小节 Tonic Chord 单列 C，Crescendo 则称为携带 A 碎片的过渡，Gauldin 也称只有一个抒情插段；本轮按过渡命名，只标 `evidence` 并保留分类分歧。第243–251小节为短华彩，第252小节进入大调尾声；第252–270小节把 B 的歌唱旋律扩为全乐队高潮，符合 Gauldin 的 apotheosis 描述。第271–301小节是终结性收束，不宣称是单一旋律主题。
