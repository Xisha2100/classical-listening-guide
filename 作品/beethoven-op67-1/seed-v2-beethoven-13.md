# 尾声接缝｜已经结束的C大三和弦为何又打开

374小节的弦乐并不是 C 小三和弦，而是 C、E、G。紧接着376出现 F、降 A、C，378又回到 C 大三和弦，380再次给 F 小三和弦。低音与内声部的变化使同一个高 C 被重新着色；刚像终止的落点，随即成为新的进行起点。先听大提琴的根音变化，再加入弦乐和弦，会比只听最高音更容易发现这件事。

因此，本导听把374列为重叠的尾声入口，并保留MTSU从376算起的另一种界定。两种边界强调的是不同层次：前者包括那个双重作用的终止和弦，后者突出新的和声转向。不能为了让图表整齐，就把374错误标成降 E 或声称尾声从头至尾只有一个和弦。真正值得听的是终止如何被重新打开，以及尾声为何还需要相当长的过程才能结束。
